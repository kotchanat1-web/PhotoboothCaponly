# ตั้งค่ากล้องแบบ webcam (ทดลอง — DEC-015)

ใช้ได้ 2 แบบ:
- **W1** — webcam USB ทั่วไป (แนะนำ 4K หรือ 1080p ที่ติดตั้งแนวตั้ง)
- **W2** — Canon EOS 70D เป็น webcam ผ่านโปรแกรม **Canon EOS Webcam Utility** (ฟรี, ทางการของ Canon, ไม่ต้องสมัคร SDK)

> ข้อจำกัดของ webcam: ตั้ง shutter / รูรับแสง / ISO จากแอปไม่ได้ (PRD CAM-1) — ตั้งที่ตัวกล้องหรือในโปรแกรมของกล้องแทน
> รูปที่ได้คือเฟรมจาก video ไม่ใช่ภาพนิ่งเต็มเซนเซอร์

---

## 1. ติดตั้ง (เฉพาะ W2 — Canon EOS 70D)

1. ดาวน์โหลด **EOS Webcam Utility** สำหรับ Windows จากเว็บ Canon (เช่น https://www.canon.com.au/apps/eos-webcam-utility หรือเว็บ Canon ประเทศไทย) — รองรับ Windows 10/11 64-bit
2. ตรวจในหน้าดาวน์โหลดว่า **EOS 70D** อยู่ในรายการกล้องที่รองรับ (ประกาศปี 2020 มี 70D) — ถ้าเวอร์ชันปัจจุบันไม่มี 70D ให้แจ้ง AI
3. ปิดโปรแกรมอื่นที่ใช้กล้องอยู่ (เช่น EOS Utility, โปรแกรมตู้เดิม `C:\PhotoboothQr`) — กล้องต่อได้ทีละโปรแกรม
4. ที่ตัวกล้อง *(คำแนะนำทั่วไป — ยังไม่ได้ทดสอบกับ 70D)*:
   - ปิด **Auto power off**
   - ใช้ไฟบ้าน (AC adapter / แบตปลอม) แทนแบตเตอรี่ ถ้าใช้ทั้งวัน
   - ต่อสาย USB ตรงเข้าเครื่อง ไม่ผ่าน hub
5. Windows: **Settings → Privacy & security → Camera** → เปิด "Let desktop apps access your camera"

## 2. ตั้งค่าแอป

สร้างไฟล์ `app\config\local.json` (ตอนรันด้วย `npm run dev` — ตำแหน่งไฟล์สำหรับตัวติดตั้ง Windows จะกำหนดตอนทำ installer):

```json
{
  "camera": {
    "driver": "webcam",
    "rotation": 0,
    "webcam": { "deviceLabel": "EOS Webcam Utility" }
  }
}
```

| ค่า | ความหมาย |
|---|---|
| `driver` | `"webcam"` = ใช้กล้องแบบ webcam (`"mock"` = กล้องจำลอง) |
| `webcam.deviceLabel` | ส่วนหนึ่งของชื่อกล้อง เช่น `"EOS Webcam Utility"`, `"Logitech"` — เว้นว่าง `""` = ใช้กล้องตัวแรกที่เจอ ถ้าชื่อไม่ตรงกับกล้องตัวไหนเลย ตู้จะขึ้น "ตู้ไม่พร้อมใช้งาน" (ไม่แอบใช้กล้องตัวอื่น) |
| `rotation` | การติดตั้งกล้อง: `0` แนวนอน, `90` หรือ `270` แนวตั้ง (ลองทั้งสองค่าว่าค่าไหนภาพตั้งตรง), `180` กลับหัว |
| `webcam.idealWidth/idealHeight` | ความละเอียดที่ขอ (ค่าเริ่มต้น 3840×2160) — กล้องจะให้เท่าที่ทำได้ ไม่ต้องแก้ |

## 3. ทดสอบ

1. เปิดแอป แตะเริ่ม เลือกกรอบ ถ่ายให้ครบ 1 รอบ
2. เปิด log วันนี้:
   - Mac: `~/Library/Application Support/photobooth/logs/booth-YYYY-MM-DD.log`
   - Windows: `%APPDATA%\photobooth\logs\booth-YYYY-MM-DD.log`
3. หาบรรทัด **`camera.ready`** — บอกชื่อกล้องที่ใช้ (`model`), ความละเอียดจริงหลังหมุน (`width`, `height`) และรายชื่อกล้องทั้งหมดที่เครื่องเห็น (`devices`) — ใช้ชื่อจาก `devices` ใส่ใน `deviceLabel`
4. ถ้ามีบรรทัด **`capture.low_resolution`** แปลว่าภาพเล็กกว่าช่องในกรอบ (`upscale` > 1 = ต้องขยายภาพ รูปพิมพ์จะนุ่ม)
5. ส่งบรรทัด `camera.ready` และ `capture.low_resolution` (ถ้ามี) ให้ AI — **อย่าส่งรูปลูกค้าจริง**

## 4. ความละเอียดที่ต้องการ (จากกรอบจริง 21 แบบ)

| แหล่งภาพ (หลังหมุน) | ช่องทั่วไป ~1000×1500 | ช่องใหญ่สุด 1447×1950 (4x6-101) |
|---|---|---|
| 1920×1080 (แนวนอน) | ขยาย ×1.4 🟡 | ขยาย ×1.81 🔴 |
| 1080×1920 (1080p ติดตั้งแนวตั้ง) | พอดี ✅ | ขยาย ×1.34 🟡 |
| 3840×2160 (4K แนวนอน) | เกินพอ ✅ | พอดี ✅ |
